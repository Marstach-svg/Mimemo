# 🌐 アプリ名（Mimemo）

## 📝 概要
<br>
リアルタイム文字起こしアプリです  <br>
リアルタイムで音声を文字起こししながら、画面に表示していきます。  <br>
文字起こしした内容のtxtファイルでのダウンロードや内容を要約した議事録の作成・ダウンロードに対応します。  <br>
会議の書記をする手間を失くします。<br>

## 🔧 主な機能
- Transcript
    - リアルタイム音声文字起こし機能
    - 文字起こしテキストダウンロード機能
    - 議事録作成機能

- User
    - ログイン・ログアウト機能（ユーザ認証）
    - マイページ機能（作成した会議一覧）
    - ユーザー設定機能（ユーザー情報更新）
---

## 🛠️ 使用技術

- フロントエンド: HTML / CSS(TailwindCSS) / JavaScript
- バックエンド: Python（Django)
- データベース: sqlite（ローカルでの使用を想定しているため　デプロイ時はDB変更）
