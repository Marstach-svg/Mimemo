# 🌐 アプリ名（Mimemo）

## 📝 概要
リアルタイム文字起こしアプリです
リアルタイムで音声を文字起こししながら、画面に表示していきます。
文字起こしした内容のtxtファイルでのダウンロードや内容を要約した議事録の作成・ダウンロードに対応します。
会議の書記をする手間を失くします。
